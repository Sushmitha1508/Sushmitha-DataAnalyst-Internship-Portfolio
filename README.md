## About This Internship

Over four progressive stages, I took a single retail sales dataset (1,000 orders, 947 customers) from raw, messy data all the way to a stakeholder-ready business narrative — backed by statistical validation. Each stage built directly on the last: cleaning fed the SQL analysis, the SQL findings shaped the segmentation, and the segmentation was statistically tested before being packaged into a final presentation.

**Headline finding across the whole project:** 94.5% of customers were one-time buyers, and customer value is driven by purchase behavior — not demographics. This single insight threads through every task below.

## Key Learnings

- **Data quality shapes every downstream decision.** Issues like inconsistent customer names and duplicate order IDs, caught early, prevented flawed conclusions later in the segmentation and testing stages.
- **The "obvious" segmentation variable isn't always the useful one.** Both K-Means clustering and a formal Chi-squared test (p = 0.526) confirmed that gender doesn't meaningfully predict customer value — purchase behavior does.
- **A single retention statistic can reframe an entire strategy.** Finding that 94.5% of customers were one-time buyers shifted the recommended focus from acquisition to retention.
- **Statistical rigor makes a narrative credible.** Pairing the segmentation story with a formal hypothesis test turned an interesting pattern into a defensible business conclusion.
- **Interactivity changes how insights land.** Moving from a static dashboard mock-up (Task 2) to a live, filterable Power BI dashboard (Task 3) made the same data far more explorable for a stakeholder.
